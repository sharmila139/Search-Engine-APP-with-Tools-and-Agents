# 🔎 AI-Powered Search Chatbot using LangChain, Groq & Streamlit

This project is a smart chatbot that combines **LLaMA3 (via Groq)**, **LangChain Agents**, and **Streamlit** to answer your questions by searching the **web**, **Arxiv**, and **Wikipedia**. It provides real-time chat experience powered by tool-augmented reasoning and memory of your past queries.

---

## 🚀 Features

- 💬 Conversational memory with chat history
- 🧠 LLaMA3-8b (via Groq) for intelligent, fast responses
- 🔍 Built-in tools:
  - Web Search
  - Arxiv Paper Lookup
  - Wikipedia Access
- ⚙️ LangChain Agent (`ZERO_SHOT_REACT_DESCRIPTION`) for tool reasoning
- 📤 Live streaming of answers with Streamlit UI
- 🔌 Easy-to-extend modular design
